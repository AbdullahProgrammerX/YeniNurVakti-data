# Nur Vakti — veri

Nur Vakti uygulamasının okuduğu hazır veri. `YeniNurVakti/pipeline` tarafından otomatik üretilir; elle düzenlemeyin.

| Dosya | İçerik |
|---|---|
| `v1/locations.json` | 81 il, 869 ilçe, kıble açıları |
| `v1/times/{ilçeId}.json` | Namaz vakitleri (ayın 1'inden gelecek yıl sonuna), bayram namazı saatleri |
| `v1/religious_days.json` | Dini günler ve kandiller |
| `v1/daily_content.json` | Günün âyeti, hadisi, duası (yılın gününe göre, her gün birikir) |
| `v1/vecizeler.json` | Risale-i Nur vecizeleri (Külliyat metniyle doğrulanmış) |
| `v1/dini_gunler.json` | Dini günlerin önemi, ibadetler, âyet ve hadisler |

Kaynaklar: T.C. Diyanet İşleri Başkanlığı Namaz Vakitleri Servisi (awqatsalah.diyanet.gov.tr);
